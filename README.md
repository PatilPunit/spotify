# 🎵 Spotify Data Analysis Project

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on Spotify music data to discover patterns, trends, and insights related to song popularity, genres, artists, and audio features. The analysis involves data cleaning, preprocessing, visualization, and statistical exploration using Python libraries.

---

## 🎯 Objectives

* Understand the structure of Spotify music data.
* Perform data cleaning and preprocessing.
* Handle missing values, duplicates, and outliers.
* Analyze relationships between audio features and song popularity.
* Identify the most popular genres and artists.
* Visualize trends using various charts and plots.
* Generate actionable insights from the dataset.

---

## 📂 Dataset Information

The dataset contains information about Spotify tracks, including:
